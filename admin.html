🔑 Conexión Directa con tu Repositorio de GitHub

Conecta tu repositorio una sola vez para que cada foto que subas o portada que cambies se guarde directamente en GitHub al instante, sin descargar archivos ni carpetas.

¿Cómo obtener tu Token de GitHub en 30 segundos? (Haz clic aquí)
  1. Entra a GitHub e inicia sesión con tu cuenta.
  2. Haz clic en este enlace directo: Generar Token en GitHub.
  3. En Note escribe: Album Boda.
  4. En Expiration puedes elegir No expiration o 90 días.
  5. Marca la casilla repo (acceso para subir fotos al repositorio).
  6. Baja al final y haz clic en el botón verde Generate token.
  7. Copia el código que te da (empieza con ghp_...) y pégalo arriba. ¡Se quedará guardado en tu navegador!
